# FIXED Instructor Full Pack — Challenge 04, Join the Happy Club

## Folders

- **student/**: ready-to-open HTML/CSS starter with real form controls and extensive CSS TODOs, SVG artwork, welcome demo, instructions, and **all four references**.
- **solution/**: finished HTML/CSS solution restored to visually match the reference screenshots, welcome demo, illustration, and **all four references**.
- **references/**: desktop, tablet, mobile and 320px reference images at the top level too.
- **CHALLENGE.md**: student assignment and grading rubric.

## Quick start

1. Give `student/` to learners, **not** the full instructor pack.
2. Learners open `student/index.html` in a browser, then follow `student/CHALLENGE.md`.
3. Open `solution/index.html` to inspect the final target.
4. Open `references/reference-desktop.png` and `references/reference-mobile.png` for the images to clone.

The starter is deliberately visually simpler than the solution, so students still have a real CSS challenge. Both versions run offline without any framework, package manager or JavaScript.
