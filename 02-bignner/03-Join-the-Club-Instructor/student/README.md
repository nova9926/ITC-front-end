# 🎨 Join the Happy Club — STUDENT STARTER

1. Open `references/reference-desktop.png` and `references/reference-mobile.png`.
2. Open `index.html` in Chrome or Live Server. **The starter is intentionally plain**, not broken.
3. Edit `style.css` to match the references. The TODO comments give you the order.
4. The HTML already contains native controls, correctly linked labels and validation.
5. When all fields are valid, the form opens the local `welcome.html` example page.
6. Do NOT submit real passwords to a demo form. This project has no backend.

For requirements, read `CHALLENGE.md`. Images are in `references/` and `assets/`.
