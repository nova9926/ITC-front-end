# CHALLENGE 01 — My Little Profile ✿

**Level:** Absolute beginner  
**Suggested time:** 1–2 hours  
**Tech:** HTML5 + CSS3 ONLY  
**Goal:** Clone the attached desktop reference and make the card work on phones.

## Your mission

Build a cute, professional-looking profile card for **Milo Bloom**, an aspiring web designer who loves iced coffee. This is **one card**, not a full landing page.

## The card must include

1. A small brand label above the card: `tinyspace.`
2. A colorful cover banner with decorations and a short slogan.
3. A round profile picture, overlapping the bottom of the banner.
4. A small green availability badge: `Open to cute projects`.
5. Name: `Milo Bloom`, username: `@milomakesstuff`.
6. A funny, one- or two-sentence bio.
7. Three stats: `12 Projects`, `1.4k Friends`, `99+ Coffee breaks`.
8. Three colored interest tags: `HTML`, `CSS`, `Iced coffee`.
9. A prominent `Say hello` contact link.
10. A tiny footer message under the card.

## Requirements

- Use **semantic HTML** where possible (`main`, `article`, `h1`, `p`, `a`).
- Keep HTML in `index.html` and CSS in `style.css`.
- **No JavaScript, frameworks, or CSS libraries**.
- Use the supplied `assets/milo-avatar.svg` image (works offline).
- On mobile, the card must fit without horizontal scrolling.
- The contact CTA must be a real `<a>` link (for example, `mailto:hello@example.com`).

## Optional bonus tasks

- Add a hover animation to the contact button.
- Add a keyboard focus style to the contact button.
- Draw decorative circles using only CSS.
- Replace Milo's information with your own profile information.

## Suggested workflow

1. Write the HTML content and verify it appears on the page.
2. Give the card a width, white background, rounded corners and shadow.
3. Style the cover banner, then overlap the avatar using a negative margin.
4. Use **Flexbox** to line up the stats and tags.
5. Style the button, spacing, typography and colors.
6. Test at desktop and mobile widths.

## Submission checklist

- [ ] Profile structure matches the reference.
- [ ] Content is readable and correctly aligned.
- [ ] The picture is circular and overlaps the banner.
- [ ] All three stats and tags are visible.
- [ ] Button is keyboard-accessible and has a working link.
- [ ] No sideways scroll on mobile.
- [ ] Only HTML + CSS were used.
