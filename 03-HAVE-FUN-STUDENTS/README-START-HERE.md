# HAVE FUN — Five HTML + CSS Landing Page Challenges

This pack is the organized version of your uploaded `03-have fun.zip`. It includes **five different finished landing-page projects**.

These are designed as the **next level AFTER the day-one HTML/CSS exercises**.

## Students
- Each project has an unfinished `index.html` and `style.css`.
- `assets/` includes artwork exported from the completed websites.
- `references/` has desktop and mobile screenshots showing the final target.
- `CHALLENGE.md` and `CONTENT-GUIDE.md` provide instructions.
- No completed source code is included in the student pack.

## Instructors
The FULL PACK includes both student projects and the finished original websites inside `INSTRUCTOR-SOLUTIONS/`.

## How to use
1. Give students **only the STUDENT ZIP**.
2. Let each student choose a project or assign one by theme.
3. They can open `index.html` directly in a browser: no setup needed.
4. Show them desktop reference, then mobile reference as optional bonus.
5. Keep the instructor ZIP private.

## Project order
01. Capy Café — cute café
02. Oops! Space Tours — cosmic travel
03. Museum of Useless Things — vintage museum
04. Ducklympics — sports comedy
05. Lost Sock Adoption Center — funny sock shelter

**Tech:** HTML5 and CSS3 only. No JavaScript, React or CSS frameworks.

**Artwork note:** The full solutions draw several illustrations with CSS. The student packs include exported illustration images instead, so students can concentrate on page layout rather than recreating complex artwork.
