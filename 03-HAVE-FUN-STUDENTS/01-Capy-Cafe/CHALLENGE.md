# Capy Café — Student Challenge

## Goal
Recreate the finished website shown in `references/reference-desktop.png` using **HTML and CSS only**.
This is a **later-stage landing-page challenge**, not a day-one exercise.

## Files you have
- `index.html` — an **unfinished starter page**, with a header, hero, and some section examples
- `style.css` — an **unfinished CSS starter**, with explanatory TODO comments
- `assets/` — ready-to-use illustration images (PNG and/or SVG), so you do **not** need to code the drawings
- `references/reference-desktop.png` — screenshot of the complete instructor website
- `references/reference-mobile.png` — mobile screenshot for the optional responsive exercise
- `CONTENT-GUIDE.md` — labels and section content to help you recreate the design

## Your task
1. Open `index.html` in a browser and see the unfinished page.
2. Start with the site header, text, and colors.
3. Recreate the hero area using `assets/hero-art.png`.
4. Build the cards and other content sections shown in the design.
5. Add spacing, background colors, borders, type sizes, and buttons.
6. Improve mobile layout when ready.

## Required sections
- Treat yourself, cutie!
- Meet our hardworking crew
- Come for coffee. Stay for the vibes.
- Header/navigation, hero, and footer
- Any other visually important sections visible in the reference screenshot

## Colors
#fffaf3 / #4d342b / #ed8d76 / #e3f1e7

## Rules
- HTML + CSS only; do not use JavaScript, React, Bootstrap or Tailwind.
- Use images provided under `assets/`. No external image URLs needed.
- The starter is **not the solution**. It intentionally leaves lots for you to implement.
- Some illustrations in the complete site were originally drawn with CSS; images are provided to simplify the challenge.

## Suggested pace
Day 1 HTML structure / Day 2 typography & colors / Day 3 hero / Day 4 cards / Day 5 other sections / Day 6 mobile / Day 7 final polish.
