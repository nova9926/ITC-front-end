# FOUR TRUE DAY-ONE HTML / CSS CHALLENGES

These challenges are for people who learned what HTML and CSS mean **today**.

| # | Challenge | Time | Allowed | New idea |
|---|---|---|---|---|
| 01 | Meet Momo the Hamster | 20–30 min | HTML only | headings, paragraphs, images and bullet lists |
| 02 | Moon Pancakes Recipe | 30–40 min | HTML only | numbered lists and strong text |
| 03 | Sunshine Lemonade Party | 30–45 min | HTML + tiny CSS | change background/text colors and center one heading |
| 04 | Adopt Pip Card | 45–60 min | HTML + basic CSS | one `class`, `padding`, `border`, `margin: auto` |

## Rules for students
- Challenge 01 and 02: No CSS at all. White page and normal browser text are expected.
- Challenge 03: Only `body`, `h1`, `h2` CSS selectors.
- Challenge 04: Only `body`, `.card`, `h1`, `a` CSS selectors.
- No JavaScript, frameworks, Flexbox, CSS Grid or media queries in any project.
- Open `index.html` in a browser. Internet, npm and extensions are not required.

## Folder structure
Each challenge includes `STUDENT/` (unfinished starter), `SOLUTION/` (complete answer), `CHALLENGE.md` (step-by-step brief) and `references/` (real screenshots of the finished answer).

For teaching: send only the student ZIP for the relevant challenge. The master pack includes the answers.
