# Challenge 03 — Sunshine Lemonade Party

**Level:** First day learning CSS  
**Time:** 30–45 minutes  
**Allowed:** Basic HTML + a **tiny** CSS file — NO JavaScript

## Your mission

All HTML content is already written. Your main job is to use **three CSS selectors** in `style.css`.

1. In `body`, set `background-color: #fff9d8;` and `color: #4b3b32;`.
2. In `h1`, set `color: #e37428;` and `text-align: center;`.
3. In `h2`, set `color: #558b55;`.
4. Save `style.css`, refresh the browser, and compare to the screenshot.

**New terms:** selector, property, value. A rule looks like `h1 { color: orange; }`.

## How to open
Open `index.html` in a browser. It already links to `style.css`.

## You succeed when
Your page has a light yellow background, brown text, an orange centered heading, and green subheadings.

## Important
No Flexbox, CSS Grid, classes, buttons, animations, or media queries.
