# Challenge 01 — Meet Momo the Hamster

**Level:** First day learning HTML  
**Time:** 20–30 minutes  
**Allowed:** HTML only — **NO CSS, NO JavaScript**

## Your mission

Recreate the provided screenshot as a tiny web page about Momo the hamster. A simple white page with browser-default styling is **correct**. Don't try to center it or add colors!

1. Make a title using `<h1>` (already started).
2. Add an introduction using `<p>`.
3. Show the provided hamster image using `<img src="assets/momo.svg" alt="Momo" width="220">`.
4. Write a heading using `<h2>`.
5. Add three favorite things using `<ul>` and `<li>`.
6. Add one more heading and a fun fact using `<p>`.

**Optional:** Try `<strong>` for bold and `<em>` for italic text.

## How to open
Open `index.html` directly in a browser. The picture is already included in `assets/`.

## You succeed when
You can see a title, a paragraph, Momo's picture, two headings, a list and a fun fact. Use `references/reference-desktop.png` as the target.

## Important
There is **no `style.css` file** in this challenge. Do not create one.
