# Challenge 02 — Moon Pancakes Recipe

**Level:** First day learning HTML  
**Time:** 30–40 minutes  
**Allowed:** HTML only — **NO CSS, NO JavaScript**

## Your mission

Make one simple recipe page. Browser-default black text on white is correct.

1. Keep the `<h1>` and introduction already provided.
2. Add the picture using `<img src="assets/pancakes.svg" alt="Pancakes" width="240">`.
3. Create an **Ingredients** heading with `<h2>`.
4. Make a bullet list with `<ul>` and `<li>` for: flour, egg, milk, sugar.
5. Create a **How to make them** heading with `<h2>`.
6. Make a numbered list with `<ol>` and `<li>` for mixing, pouring, cooking and topping.
7. Finish with a small Chef's tip paragraph.

**Optional:** Add `<strong>` around the words Chef's tip.

## How to open
Open `index.html` in a browser. Everything works offline.

## You succeed when
Your page has an image, one ingredients list with bullet points, and one steps list with numbers.

## Important
**Do not use CSS**. This challenge is about HTML structure, not appearance.
