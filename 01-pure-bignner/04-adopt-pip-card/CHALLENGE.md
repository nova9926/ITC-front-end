# Challenge 04 — Adopt Pip Card

**Level:** First day learning CSS, one step above Challenge 03  
**Time:** 45–60 minutes  
**Allowed:** Basic HTML + basic CSS — NO JavaScript

## Your mission

The HTML is already written and the puppy picture is provided. Style a **single** card with simple CSS.

1. For `body`, set a pale blue `background-color`, a text `color`, and `text-align: center`.
2. For `.card`, try `background-color: white;`.
3. Give the card `width: 250px;`.
4. Add space inside the card: `padding: 20px;`.
5. Add space around the card: `margin: 30px auto;`.
6. Add a simple `border: 2px solid #94bde8;`.
7. Change the colors of `h1` and `a`.

**New term:** `.card` is a **class selector**. It styles an element with `class="card"`.

## How to open
Open `index.html` in a browser. It already links to `style.css`.

## You succeed when
The puppy appears inside a white card centered on a light blue page. Compare to the supplied screenshot.

## Important
No Flexbox, Grid, shadows, complex selectors, animations, or JavaScript. `margin: auto` is the only new layout trick.
