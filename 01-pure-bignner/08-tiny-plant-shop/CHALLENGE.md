# Challenge 04: Little Leaf — Tiny plant shop

**Time:** 90–120 minutes  
**Level:** Level 4 of 4 — slightly harder  
**Allowed:** HTML5, beginner CSS, your provided SVG assets.  
**Not allowed:** JavaScript, frameworks, Flexbox, CSS Grid, animation, or external libraries.

## Your mission
Recreate the **reference-desktop.png** design. Use **reference-mobile.png** as inspiration for smaller screens. Start with `student/index.html` and `student/style.css`.

## Required elements
1. Build a small shop with a title and three plant cards.
2. Each card needs an image, name, description, price and link.
3. Use display:inline-block (not Flexbox/Grid) to create three columns on desktop.
4. Use basic CSS to style each card consistently.

## What you will practice
Reusable cards, inline-block layout, width, spacing and a simple media query.

## Optional bonus
Use one media query to stack cards on phones. The links are sample email links, not real checkout.

## How to run it
Open `student/index.html` in any browser. No installation or internet needed. Work in VS Code if you like.

## Important
- The student files are **intentionally unfinished but not empty**. Complete the HTML `TODO` comments and CSS rules.
- Provided SVG art is ready to use; you don't need to draw it.
- Reference screenshots are **targets**, not the student starter output.
- Use clear semantic HTML tags and descriptive alt text.
- Links using `example.com` are fictional samples.
